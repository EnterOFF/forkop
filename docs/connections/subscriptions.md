# Подписка

Ссылка на подписку VPN-сервиса или путь к [файлу на роутере](#подписка-из-фаила). Подходят списки ссылок, Clash и mihomo, sing-box, Xray, SIP008 и base64. Серверы протоколов, которых нет в установленной [сборке ядра](/guide/install#сборки-ядра), пропускаются.

## Обновление

Подписка обновляется раз в **Интервал обновления**, по умолчанию раз в час, а все подписки сразу обновляет кнопка **Обновить подписки** на дашборде. Если обновить не удалось, секция работает на прежних серверах.

Если панель сервиса заблокирована у провайдера, включите **Запрашивать через секцию** и выберите секцию с рабочим подключением.

## Подписка из файла

Вместо ссылки можно указать полный путь к файлу на роутере, например `/etc/forkop/servers.txt`. Папка `/etc/forkop/` переживает обновление прошивки. Форматы те же, проще всего написать ссылки по одной в строке:

```text
vless://uuid@nl.example.com:443?security=reality&pbk=…&sid=…&sni=www.microsoft.com#Нидерланды
hysteria2://password@fi.example.com:443#Финляндия
ss://…@de.example.com:8388#Германия
```

После правки файла серверы обновятся сами, без перезапуска.

## Заголовки

Forkop сам заполняет заголовки запроса к панели, а кнопка **Редактировать** у **Заголовков** позволяет их поменять.

### User-Agent

По `User-Agent` сервис узнаёт приложение и решает, что ему отдать. Некоторые сервисы отдают все серверы только своим приложениям, другие прячут XHTTP и Hysteria2 от приложений, которые их не поддерживают.

Если серверов меньше, чем в приложении на телефоне, или подписка пришла пустой, поставьте `User-Agent` популярного приложения и обновите подписку:

| User-Agent | Приложение |
| --- | --- |
| `Happ` | Happ |
| `Incy` | Incy |
| `v2rayNG` | v2rayNG для Android |
| `v2rayN` | v2rayN для Windows |
| `mihomo` | клиенты на ядре mihomo |
| `clash.meta` | Clash Meta и совместимые |

### X-HWID

По `X-HWID` сервис узнаёт устройство. Forkop вычисляет его из MAC-адреса и модели роутера, поэтому после перезагрузки и переустановки роутер остаётся тем же устройством.

Если подписка ограничивает число устройств, впишите на роутере тот же `X-HWID`, что у приложения на другом устройстве, и сервис посчитает их одним.

## Параметры серверов

Меняют все серверы подписки сразу.

### Префикс и суффикс

Добавляют текст к имени каждого сервера. Так серверы подписки легко отличить на дашборде и отобрать в фильтрах [URLTest](/connections/urltest) и [Fallback](/connections/fallback), например префикс `Work ` и шаблон `^Work`.

### Переименование серверов

Правила `шаблон => замена`, по одному в строке. Шаблон пишется регулярным выражением, как в [фильтре](#шаблоны). Правила работают по порядку, каждое видит результат предыдущего, а префикс и суффикс добавляются после них.

| Правило | Было | Стало |
| --- | --- | --- |
| `^HK-(.*)$ => Гонконг $1` | `HK-01` | `Гонконг 01` |
| `🇩🇪 => DE` | `🇩🇪 Берлин` | `DE Берлин` |
| `\s*\[Premium\]$ =>` | `Германия [Premium]` | `Германия` |

`$1` вставляет то, что попало в первые скобки шаблона. Если сразу за ним идёт буква, пишите `${1}`. Пустая замена удаляет найденный текст.

### JSON

Объект, который сливается с настройками каждого сервера. Так меняют то, чего нет в ссылках, например отпечаток браузера:

```json
{
  "tls": {
    "utls": { "enabled": true, "fingerprint": "firefox" }
  }
}
```

Вложенные объекты дополняются, а не заменяются целиком: в примере у `tls` меняется только `utls`. `null` удаляет поле, например `{"multiplex": null}` выключит мультиплекс, который включила панель. Поля, которых у протокола нет, пропускаются: `tls` не тронет Shadowsocks. Поля называются так же, как в [документации sing-box](https://sing-box.sagernet.org/configuration/outbound/).

## Фильтр серверов

Фильтр решает, какие серверы подписки попадут в секцию. Так же устроены фильтры [URLTest](/connections/urltest) и групп [Fallback](/connections/fallback).

| Режим | Что попадёт в секцию |
| --- | --- |
| **Все серверы** | вся подписка |
| **Кроме выбранных** | вся подписка, кроме исключённого |
| **Только выбранные** | только включённое |

Поля «Включить» есть только у **Только выбранные**, и серверу достаточно попасть в одно из них. Поля «Исключить» есть у обоих режимов и убирают лишнее, в том числе из уже включённого.

Панель может переименовать сервер или убрать его, поэтому шаблоны надёжнее выбора из списка. Например, убрать российские серверы: **Кроме выбранных** и **Исключить по шаблону** `(?i)россия|russia|🇷🇺`.

### Шаблоны

Шаблон — регулярное выражение, которое ищет совпадение в любом месте имени сервера. `(?i)` в начале выключает различие регистра, `|` означает «или».

| Шаблон | Что найдёт |
| --- | --- |
| `(?i)amsterdam\|netherlands\|🇳🇱` | Нидерланды в любом написании и по флагу |
| `^DE` | имена, которые начинаются с «DE» |
| `(?i)\b(premium\|vip)\b` | серверы с пометкой premium или vip |

Проверить шаблон можно на [regex101.com](https://regex101.com/) с вариантом Golang.
